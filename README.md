# FUNDAMENTOS_PROGRAMACI-N
# MESA DE PARTES DIGITAL
## Fe y Alegría N.º 37

Descripción
Sistema desarrollado en Python para gestionar
expedientes escolares y registrar calificaciones.

Funcionalidades
1. Registrar expedientes.
2. Listar expedientes.
3. Buscar expedientes por código.
4. Ordenar expedientes.
5. Actualizar estado del trámite.
6. Registrar calificaciones.
7. Guardar información en CSV.
8. Eliminar expedientes.
9. Modificar expedientes.
